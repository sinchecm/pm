# Kanban Studio

Project management Kanban board with an AI assistant. Runs locally in Docker.

Requires Docker and a `.env` file in the project root containing `OPENROUTER_API_KEY`.

## Run

- Mac/Linux: `scripts/start.sh` / `scripts/stop.sh`
- Windows: `scripts/start.ps1` / `scripts/stop.ps1`

Then open http://localhost:8001.
